# Chittoor Transportation Planning

Transportation planning study assessing the impacts of infrastructure
development on the transportation network of Chittoor district.

## Tools
- QGIS
- Aequilibrae
- Python
- NumPy
- Pandas

## Methodology

Network Preparation
→ Cost Matrix
→ Trip Generation
→ Trip Distribution
→ Traffic Assignment
→ Scenario Analysis
→ Economic Analysis

## Study Area

The study consists of 11 Transportation Analysis Zones (TAZs)
in Chittoor district.

## Key Methods

- OLS regression for trip generation
- Doubly constrained gravity model for trip distribution
- Aequilibrae-based traffic assignment
- Multi-scenario infrastructure analysis
- Vehicle Hours Travelled (VHT) analysis

## Key Results

The base network VHT was 7,715.68 veh·hr/day.

Four infrastructure improvement scenarios were evaluated.
The fourth scenario produced a 16.04% reduction in VHT.
